= Configure a Hugging Face access token on OpenShift

[role="_abstract"]
To add private Hugging Face catalog sources, you must first configure a Hugging Face access token on {openshift-platform}. The access token allows {productname-short} to authenticate with Hugging Face and retrieve model information from your organizations.

.Prerequisites

* You are logged in to {openshift-platform} with cluster administrator privileges.
* You have a Hugging Face account.

.Procedure

. Create a Hugging Face access token:
+
.. Navigate to link:https://huggingface.co/settings/tokens[Hugging Face access tokens settings] in your web browser.
.. Click *New token*.
.. Enter a name for the token and select *Read* as the token type.
.. Click *Generate token*.
.. Copy the generated token for use in the next step.
+
[NOTE]
====
The token is shown in full only once. If you do not copy it now, you must generate a new token.
====

. Create or update the Kubernetes secret that stores the Hugging Face API key:
+
[source,terminal,subs="+quotes"]
----
$ oc create secret generic model-catalog-hf-api-key \
  --from-literal=HF_API_KEY=_<your-hugging-face-token>_ \
  -n model-catalog \
  --dry-run=client -o yaml | kubectl apply -f -
----
+
_<your-hugging-face-token>_ specifies the Hugging Face access token that you created in the previous step.
+
This command creates or updates the `model-catalog-hf-api-key` secret in the `model-catalog` namespace. The catalog server reads the token from the `HF_API_KEY` environment variable.

. Restart the catalog server to apply the new secret:
+
[source,terminal]
----
$ oc rollout restart deployment/model-catalog-server -n model-catalog
----

. Wait for the catalog server to restart:
+
[source,terminal]
----
$ oc rollout status deployment/model-catalog-server -n model-catalog
----

.Verification

. In the {productname-short} dashboard, click *Settings* -> *Model resources and operations* -> *Model catalog settings*.

. Click *Add a source*.

. Select *Hugging Face repository* as the catalog source type.

. Enter a Hugging Face organization name, such as `meta-llama`, and verify that you do not receive an access token error.

. Enter a Hugging Face organization name, such as `meta-llama`. Verify that no access token error is displayed. You can then either complete the source addition or cancel.

[NOTE]
====
If you previously attempted to add a Hugging Face catalog source without configuring the access token, you might need to refresh your browser page to clear the error.
====
