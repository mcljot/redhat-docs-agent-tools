= Use benchmark collections for domain-specific evaluation

[role="_abstract"]
You can run pre-defined or custom benchmark collections to evaluate a model across a coherent set of benchmarks with weighted scoring.
Collections provide a composite assessment for a specific domain, such as general capability, safety, or toxicity, without requiring you to configure each benchmark individually.

.Prerequisites

* The evaluation stack client tools are installed and configured. See xref:installing-the-evaluation-stack-client-tools_{context}[Install the evaluation stack client tools].
* A model endpoint is accessible from the OpenShift cluster.

.Procedure

. List the available benchmark collections:
+
[source,terminal]
----
$ evalhub collections list
----
+
To filter collections by tag:
+
[source,terminal]
----
$ evalhub collections list --tag safety
----

. Review the details of a collection:
+
[source,terminal]
----
$ evalhub collections describe safety-and-fairness-v1
----
+
The output shows the collection name, description, tags, pass threshold, and the benchmarks included with their weights and individual thresholds.

. Run a collection against a model:
+
--
*Using the CLI:*

[source,terminal]
----
$ evalhub collections run safety-and-fairness-v1 \
    --model-url http://vllm:8000/v1 \
    --model-name meta-llama/llama-3.1-8b
----

To wait for the evaluation to complete:

[source,terminal]
----
$ evalhub collections run safety-and-fairness-v1 \
    --model-url http://vllm:8000/v1 \
    --model-name meta-llama/llama-3.1-8b \
    --wait
----

*Using the REST API:*

[source,terminal]
----
$ curl -X POST "https://<evalhub_url>/api/v1/evaluations/jobs" \
    -H "Content-Type: application/json" \
    -H "Authorization: Bearer <token>" \
    -d '{
      "name": "safety-evaluation",
      "model": {
        "url": "http://vllm:8000/v1",
        "name": "meta-llama/llama-3.1-8b"
      },
      "collection": {
        "id": "safety-and-fairness-v1"
      },
      "experiment": {
        "name": "safety-check"
      }
    }'
----

*Using the Python SDK:*

[source,python]
----
from evalhub.client.evalhub import SyncEvalHubClient
from evalhub.models import (
    CollectionRef,
    ExperimentConfig,
    JobSubmissionRequest,
    ModelConfig,
)

with SyncEvalHubClient(
    base_url="https://evalhub.example.com",
    auth_token="<token>",
) as client:
    request = JobSubmissionRequest(
        name="safety-evaluation",
        model=ModelConfig(
            url="http://vllm:8000/v1",
            name="meta-llama/llama-3.1-8b",
        ),
        collection=CollectionRef(id="safety-and-fairness-v1"),
        experiment=ExperimentConfig(name="safety-check"),
    )
    job = client.jobs.submit(request)
    completed_job = client.jobs.wait_for_completion(job.id)
    print(f"Job {completed_job.id} finished: {completed_job.state.value}")
----
--

. Retrieve and review the collection results:
+
[source,terminal]
----
$ evalhub eval results <job_id> --format json
----
+
Each benchmark in the collection produces individual scores.
The collection-level pass/fail criteria determine whether the model meets the composite threshold based on weighted scores.

.Verification

Verify that the evaluation completed for all benchmarks in the collection:

[source,terminal]
----
$ evalhub eval status <job_id>
----

The output shows the state of each benchmark.
All benchmarks should show a `completed` state for a successful collection evaluation.

== Creating a custom collection

You can create a custom collection to group specific benchmarks with your own weights and thresholds.

. Create a collection specification file named `my-collection.yaml`:
+
[source,yaml]
----
name: My Custom Collection
description: Custom collection for domain-specific evaluation.
tags:
  - custom
  - my-domain
pass_criteria:
  threshold: 0.70
benchmarks:
  - id: arc_easy
    provider_id: lm_evaluation_harness
    weight: 2
    primary_score:
      metric: acc_norm
      lower_is_better: false
    pass_criteria:
      threshold: 0.50
    parameters:
      num_fewshot: 0
  - id: hellaswag
    provider_id: lm_evaluation_harness
    weight: 1
    primary_score:
      metric: acc_norm
      lower_is_better: false
    pass_criteria:
      threshold: 0.40
    parameters:
      num_fewshot: 0
----

. Register the collection:
+
[source,terminal]
----
$ evalhub collections create --file my-collection.yaml
----

. Verify the collection was created:
+
[source,terminal]
----
$ evalhub collections describe <collection_id>
----

To delete a custom collection:

[source,terminal]
----
$ evalhub collections delete <collection_id>
----
