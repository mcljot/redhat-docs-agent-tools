= View evaluation results in MLflow

[role="_abstract"]
You can view and compare evaluation results in MLflow when your evaluation jobs include an experiment configuration.
The evaluation stack automatically creates MLflow experiments and records metrics, parameters, and artifacts for each evaluation run.

.Prerequisites

* An evaluation job that includes an `experiment` configuration has completed. See xref:running-an-evaluation-job_{context}[Run an evaluation job].
* An MLflow instance is accessible and the evaluation stack is configured with the `MLFLOW_TRACKING_URI` environment variable.

.Procedure

. Retrieve the MLflow experiment URL from the job results:
+
[source,terminal]
----
$ evalhub eval results <job_id>
----
+
The output includes an `MLflow experiment` URL at the bottom of the results table.
+
Alternatively, use JSON output to extract the `mlflow_experiment_url` and `mlflow_run_id` fields:
+
[source,terminal]
----
$ evalhub eval results <job_id> --format json
----

. Open the MLflow experiment URL in your browser to view the experiment in the MLflow UI.

. In the MLflow UI, examine the evaluation run:
+
--
* *Metrics*: Benchmark scores and performance data are recorded as MLflow metrics.
Each metric name corresponds to the evaluation metric produced by the provider (for example, `acc_norm`, `toxicity_score`, `output_tokens_per_second`).
* *Parameters*: Model configuration and benchmark settings are recorded as MLflow parameters, including `benchmark_id`, `model_name`, `num_examples_evaluated`, and `duration_seconds`.
* *Artifacts*: Detailed result files and execution logs are stored as MLflow artifacts.
* *Tags*: Custom experiment tags that you specified in the job submission are recorded on the MLflow run.
--

. To compare results across models, select multiple runs in the MLflow experiment view and use the comparison feature.
+
This is useful when you run the same benchmarks against different models or model versions.

.Verification

Verify that evaluation metrics appear in MLflow by checking the JSON results for `mlflow_run_id` values on each benchmark result:

[source,terminal]
----
$ evalhub eval results <job_id> --format json | python3 -c "
import json, sys
data = json.load(sys.stdin)
for b in data:
    run_id = b.get('mlflow_run_id', 'N/A')
    print(f\"{b['id']} ({b['provider_id']}): mlflow_run_id={run_id}\")
"
----

Each benchmark with a non-null `mlflow_run_id` has been successfully recorded in MLflow.
