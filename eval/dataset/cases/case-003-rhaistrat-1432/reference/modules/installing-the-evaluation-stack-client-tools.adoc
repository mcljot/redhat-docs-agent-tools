= Install the evaluation stack client tools

[role="_abstract"]
You can install the EvalHub CLI and Python SDK to submit evaluation jobs, monitor their progress, and retrieve results from your workstation or CI/CD pipeline.

.Prerequisites

* Python 3.9 or later is installed.
* The evaluation stack is deployed and accessible, or a system administrator has provided the base URL.

.Procedure

. Install the CLI and SDK by using `pip`:
+
--
To install both the CLI and the Python SDK:

[source,terminal]
----
$ pip install "eval-hub-sdk[cli]"
----

To install only the Python SDK without the CLI:

[source,terminal]
----
$ pip install "eval-hub-sdk[client]"
----
--

. Verify the installation:
+
[source,terminal]
----
$ evalhub version
----

. Configure the connection to the evaluation stack:
+
[source,terminal]
----
$ evalhub config set base_url <evalhub_url> <1>
$ evalhub config set token <auth_token> <2>
$ evalhub config set tenant <tenant_namespace> <3>
----
<1> Replace `<evalhub_url>` with the URL of the evaluation stack service, for example `https://evalhub-myproject.apps.example.com`.
<2> Replace `<auth_token>` with your authentication token.
<3> Replace `<tenant_namespace>` with your tenant namespace.
+
Configuration is stored in `~/.config/evalhub/config.yaml` with secure file permissions.

. Verify the configuration:
+
[source,terminal]
----
$ evalhub config list
----

. Test the connection by checking the service health:
+
[source,terminal]
----
$ evalhub health
----

.Verification

The `evalhub health` command returns a status message with the response time:

[source,terminal]
----
EvalHub service: healthy (42ms)
----

If the service is unreachable, verify the `base_url` and `token` values in your configuration.

== Managing configuration profiles

You can create and switch between named profiles to connect to different evaluation stack instances:

. Create a profile for a production environment:
+
[source,terminal]
----
$ evalhub --profile prod config set base_url https://evalhub-prod.apps.example.com
$ evalhub --profile prod config set token <prod_token>
$ evalhub --profile prod config set tenant <prod_namespace>
----

. Switch to the production profile:
+
[source,terminal]
----
$ evalhub config use prod
----

. Override the profile for a single command:
+
[source,terminal]
----
$ evalhub --profile staging health
----

[id="ci-cd-environment-variables"]
== CI/CD environment variables

In CI/CD pipelines, you can configure the client by using environment variables instead of the configuration file:

.Environment variables for CI/CD integration
[cols="1,2", options="header"]
|===
|Variable
|Description

|`EVALHUB_BASE_URL`
|URL of the evaluation stack service.

|`EVALHUB_TOKEN`
|Authentication token.

|`EVALHUB_TENANT`
|Tenant namespace identifier.

|`EVALHUB_PROFILE`
|Configuration profile to use.

|===
