= Evaluate AI models across multiple frameworks

[role="_abstract"]
As a developer or data scientist, you can use the evaluation stack to run standardized evaluations against your AI models across multiple frameworks through a single interface.
You can assess model quality, safety, fairness, and inference performance using built-in providers and benchmark collections, and track results in MLflow experiments.

This workflow guides you through understanding the evaluation stack concepts, installing the client tools, running evaluation jobs, using benchmark collections, viewing results in MLflow, and integrating custom evaluation frameworks.
