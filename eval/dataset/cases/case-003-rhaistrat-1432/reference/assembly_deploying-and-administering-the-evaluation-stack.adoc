= Deploy and administer the evaluation stack

[role="_abstract"]
As a system administrator, you can deploy the evaluation stack on your OpenShift cluster and configure it for multi-tenant operation.
This enables development teams to submit AI model evaluations through a shared platform with namespace-based isolation and role-based access control.
