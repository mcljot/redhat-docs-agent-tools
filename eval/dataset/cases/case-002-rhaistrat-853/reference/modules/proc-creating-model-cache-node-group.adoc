= Create a model cache node group

[role="_abstract"]
You can create a `LocalModelNodeGroup` resource to define a group of nodes that store cached models.
The node group specifies the storage capacity, PersistentVolume template, and PersistentVolumeClaim template used for model downloads.

.Prerequisites

* Model caching is enabled in the `inferenceservice-config` ConfigMap.
* You have `cluster-admin` privileges on the OpenShift cluster.
* Target nodes have local storage available at the path specified in the PersistentVolume spec.

.Procedure

. Label the nodes that will participate in model caching:
+
[source,terminal]
----
$ oc label node <node_name> kserve/localmodel=worker
----
+
Replace `<node_name>` with the name of each node that should cache models.
The `kserve/localmodel=worker` label is required for the LocalModelNode agent DaemonSet to schedule pods on these nodes.

. Verify that the host directory exists on each labeled node and has the correct ownership.
The directory path must match the `local.path` value in the PersistentVolume spec.
The directory must be owned by the UID and GID matching the `fsGroup` value configured in the `inferenceservice-config` ConfigMap.
+
For example, if `fsGroup` is `1000` and the local path is `/models`:
+
[source,terminal]
----
$ ssh <node_name> "sudo mkdir -p /models && sudo chown 1000:1000 /models"
----

. Create a `LocalModelNodeGroup` resource.
The following example creates a node group named `worker-group-1` with a 500 Gi storage limit:
+
[source,yaml]
----
apiVersion: serving.kserve.io/v1alpha1
kind: LocalModelNodeGroup
metadata:
  name: worker-group-1
spec:
  storageLimit: 500Gi
  persistentVolumeSpec:
    accessModes:
      - ReadWriteOnce
    capacity:
      storage: 500Gi
    local:
      path: /models
    nodeAffinity:
      required:
        nodeSelectorTerms:
          - matchExpressions:
              - key: kserve/localmodel
                operator: In
                values:
                  - worker
    persistentVolumeReclaimPolicy: Delete
    storageClassName: ""
    volumeMode: Filesystem
  persistentVolumeClaimSpec:
    accessModes:
      - ReadWriteOnce
    resources:
      requests:
        storage: 500Gi
    storageClassName: ""
    volumeMode: Filesystem
----
+
--
Where:

`storageLimit`:: The maximum total storage available per node in this group. Set this value to match the available disk space on the target nodes.
`persistentVolumeSpec.local.path`:: The path on the host filesystem where models are stored. This path must match the `hostPath` in the LocalModelNode agent DaemonSet, which defaults to `/models`.
`persistentVolumeSpec.nodeAffinity`:: Defines which nodes belong to this group. The `matchExpressions` must select nodes labeled with `kserve/localmodel=worker`.
`persistentVolumeClaimSpec`:: The PVC template used when the controller creates PVCs for model downloads. The `storage` request should match the PV capacity.
--

. Apply the resource:
+
[source,terminal]
----
$ oc apply -f localmodelnodegroup.yaml
----

.Verification

. Verify that the LocalModelNode agent DaemonSet pods are running on the labeled nodes:
+
[source,terminal]
----
$ oc get pods -n kserve -l control-plane=kserve-localmodelnode-agent -o wide
----
+
.Example output
[source,terminal]
----
NAME                                     READY   STATUS    RESTARTS   AGE   NODE
kserve-localmodelnode-agent-xxxxx        1/1     Running   0          5m    worker-0
kserve-localmodelnode-agent-yyyyy        1/1     Running   0          5m    worker-1
----
+
One agent pod should be running on each node labeled with `kserve/localmodel=worker`.

. Verify that the `LocalModelNodeGroup` resource was created:
+
[source,terminal]
----
$ oc get localmodelnodegroup worker-group-1
----

[IMPORTANT]
====
The `local.path` value in the PersistentVolume spec must match the `hostPath` configured in the LocalModelNode agent DaemonSet.
The default DaemonSet hostPath is `/models`.
If these paths do not match, download jobs may write to the wrong location and the agent cannot detect downloaded models.
====
