= Model cache CRD API reference

[role="_abstract"]
The model cache feature introduces four custom resource definitions (CRDs) in the `serving.kserve.io` API group.
You can use this reference to look up field names, types, and validation rules when writing manifests or verifying resource configuration.

All CRDs use API version `v1alpha1`.

[#localmodelcache-api_{context}]
== LocalModelCache

* Scope: Cluster
* API group: `serving.kserve.io`
* API version: `v1alpha1`

.`LocalModelCacheSpec` fields
[cols="2,2,1,3", options="header"]
|===
|Field
|Type
|Required
|Description

|`sourceModelUri`
|String
|Yes
|The URI of the model to download. Immutable after creation (enforced by XValidation rule `self == oldSelf`). Must be unique across all `LocalModelCache` resources (enforced by validating webhook).

|`modelSize`
|`resource.Quantity`
|Yes
|The expected model size.

|`nodeGroups`
|`[]string`
|Yes (MinItems=1)
|Names of `LocalModelNodeGroup` resources to target.

|`serviceAccountName`
|String
|No
|Service account for credential lookup.

|`storage`
|`LocalModelStorageSpec`
|No
|Storage credential configuration.
|===

.`LocalModelStorageSpec` fields
[cols="2,2,1,3", options="header"]
|===
|Field
|Type
|Required
|Description

|`key`
|String
|No
|Storage key in the credential secret.

|`parameters`
|`map[string]string`
|No
|Override parameters for storage credentials.
|===

.`LocalModelCacheStatus` fields
[cols="2,2,3", options="header"]
|===
|Field
|Type
|Description

|`nodeStatus`
|`map[string]NodeStatus`
|Per-node download status. Keys are node names, values are `NodeStatus` enum.

|`copies`
|`ModelCopies`
|Aggregate availability counts.

|`inferenceServices`
|`[]NamespacedName`
|Inference services using this cache.

|`llmInferenceServices`
|`[]NamespacedName`
|LLM inference services using this cache.
|===

.`NodeStatus` enum
[cols="1,3", options="header"]
|===
|Value
|Description

|`NodeNotReady`
|Node is not available for downloading.

|`NodeDownloadPending`
|Download job created but not started.

|`NodeDownloading`
|Download in progress.

|`NodeDownloaded`
|Model successfully cached.

|`NodeDownloadError`
|Download failed.
|===

|Type

|`total`

[#localmodelnamespacecache-api_{context}]
== LocalModelNamespaceCache

* Scope: Namespaced
* API group: `serving.kserve.io`
* API version: `v1alpha1`

The `LocalModelNamespaceCacheSpec` has the same fields as `LocalModelCacheSpec`.
The status type is also `LocalModelCacheStatus`.

Additional validation rules:

* All referenced node groups must exist (validated by webhook on create and update).
* Deletion is blocked if any `InferenceService` or `LLMInferenceService` in the same namespace references the cache.

* Scope: Cluster
* API group: `serving.kserve.io`
* API version: `v1alpha1`

.`LocalModelNodeGroupSpec` fields
[cols="2,2,1,3", options="header"]
|===
|Field
|Type
|Required
|Description

|`storageLimit`
|`resource.Quantity`
|Yes
|Maximum storage capacity per node.

|`persistentVolumeSpec`
|`corev1.PersistentVolumeSpec`
|Yes
|PV template for local storage. Key fields: `local.path`, `nodeAffinity`, `capacity`, `accessModes`.

|`persistentVolumeClaimSpec`
|`corev1.PersistentVolumeClaimSpec`
|Yes
|PVC template for download jobs. Key fields: `accessModes`, `resources.requests.storage`.

|Type
|Description

|===

[#localmodelnode-api_{context}]
== LocalModelNode

* Scope: Cluster
* API group: `serving.kserve.io`
* API version: `v1alpha1`
* Managed by: LocalModel controller (do not create manually)

.`LocalModelNodeSpec` fields
[cols="2,2,1,3", options="header"]
|===
|Field
|Type
|Required
|Description

|`localModels`
|`[]LocalModelInfo`
|Yes
|List of models to cache on this node.
|===

.`LocalModelInfo` fields
[cols="2,2,1,3", options="header"]
|===
|Field
|Type
|Required
|Description

|`sourceModelUri`
|String
|Yes
|The model URI.

|`modelName`
|String
|Yes
|The model cache CR name. Used as the subdirectory name for status tracking.

|`namespace`
|String
|No
|The namespace of the `LocalModelNamespaceCache` CR. Empty for cluster-scoped `LocalModelCache`.

|`nodeGroup`
|String
|No
|The `LocalModelNodeGroup` name. Used by the agent to construct the PVC name when multiple node groups have overlapping node affinity.

|`serviceAccountName`
|String
|No
|Service account for credential lookup.

|`storage`
|`LocalModelStorageSpec`
|No
|Storage credential configuration.
|===

.`LocalModelNodeStatus` fields
[cols="2,2,3", options="header"]
|===
|Field
|Type
|Description

|`modelStatus`
|`map[string]ModelStatus`
|Per-model download status on this node. Keys are status keys: `modelName` for cluster-scoped or `namespace/modelName` for namespace-scoped.
|===

.`ModelStatus` enum
[cols="1,3", options="header"]
|===
|Value
|Description

|`ModelDownloadPending`
|Download job created but not started.

|`ModelDownloading`
|Download in progress.

|`ModelDownloaded`
|Model successfully cached.

|`ModelDownloadError`
|Download failed.
|===
