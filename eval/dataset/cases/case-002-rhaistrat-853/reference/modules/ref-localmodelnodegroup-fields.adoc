= LocalModelNodeGroup field reference

[role="_abstract"]
The `LocalModelNodeGroup` custom resource defines a group of nodes for model caching.
You can use this reference to look up field names, types, and descriptions when writing `LocalModelNodeGroup` manifests.

* API group: `serving.kserve.io`
* API version: `v1alpha1`
* Scope: Cluster

[discrete]
== Spec fields

.`LocalModelNodeGroupSpec` fields
[cols="2,2,1,3", options="header"]
|===
|Field
|Type
|Required
|Description

|`storageLimit`
|`resource.Quantity` (for example, `500Gi`)
|Yes
|The maximum total storage capacity available per node in this node group. The controller uses this value to validate that cached models do not exceed the available storage on any node.

|`persistentVolumeSpec`
|`corev1.PersistentVolumeSpec`
|Yes
|The PersistentVolume template used to create PVs on each node for storing cached models. Key fields include `local.path` (the host directory), `nodeAffinity` (selects which nodes participate), `capacity`, `accessModes`, and `storageClassName`.

|`persistentVolumeClaimSpec`
|`corev1.PersistentVolumeClaimSpec`
|Yes
|The PersistentVolumeClaim template used to create PVCs for model download jobs and inference service namespaces. Key fields include `accessModes`, `resources.requests.storage`, `storageClassName`, and `volumeMode`.
|===

[discrete]
== Status fields

.`LocalModelNodeGroupStatus` fields
[cols="2,2,3", options="header"]
|===
|Field
|Type
|Description

|`used`
|`resource.Quantity`
|The total storage space currently used for cached models on nodes in this group.

|`available`
|`resource.Quantity`
|The remaining storage space available for new cached models on nodes in this group.
|===
