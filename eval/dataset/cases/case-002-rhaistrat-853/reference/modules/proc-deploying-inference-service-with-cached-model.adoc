= Deploy an inference service with a cached model

[role="_abstract"]
You can deploy an `InferenceService` or `LLMInferenceService` that automatically uses a locally cached model instead of downloading it from a remote registry at startup.
When the inference service's `storageUri` matches a cached model, a mutating webhook configures the pod to mount the local PVC, reducing cold-start time from approximately 15-20 minutes to approximately 1 minute.

.Prerequisites

* A `LocalModelCache` or `LocalModelNamespaceCache` resource exists with at least one node in `NodeDownloaded` status.
* The inference service's `storageUri` matches the cached model's `sourceModelUri`.

.Procedure

. Create an `InferenceService` with a `storageUri` that matches the cached model.
+
The following example creates an inference service that uses a cached Hugging Face model:
+
[source,yaml]
----
apiVersion: serving.kserve.io/v1beta1
kind: InferenceService
metadata:
  name: llama-3-8b
spec:
  predictor:
    model:
      modelFormat:
        name: vllm
      runtime: vllm-runtime
      storageUri: "hf://meta-llama/Meta-Llama-3-8B-Instruct"
----
+
The `storageUri` value must match the `sourceModelUri` of the `LocalModelCache` resource.
The matching supports two modes:
+
* *Exact match*: The `storageUri` exactly equals the cached `sourceModelUri`.
* *Subdirectory match*: The `storageUri` is a subdirectory of the cached `sourceModelUri`. For example, a cache for `hf://meta-llama/Meta-Llama-3-8B-Instruct` also matches `hf://meta-llama/Meta-Llama-3-8B-Instruct/tokenizer`.

. Apply the resource:
+
[source,terminal]
----
$ oc apply -f inferenceservice.yaml
----

. Verify that the inference service is using the cached model by checking for the model cache labels and annotations:
+
[source,terminal]
----
$ oc get inferenceservice llama-3-8b -o jsonpath='{.metadata.labels}'
----
+
.Example output
[source,json]
----
{"internal.serving.kserve.io/localmodel":"llama-3-8b-cache"}
----
+
The presence of the `internal.serving.kserve.io/localmodel` label confirms that the inference service is using a cached model.
The label value is the name of the matching `LocalModelCache` resource.

. Optionally, check the PVC annotation:
+
[source,terminal]
----
$ oc get inferenceservice llama-3-8b -o jsonpath='{.metadata.annotations.internal\.serving\.kserve\.io/localmodel-pvc-name}'
----

[discrete]
=== Opt out of model caching for a specific inference service

To disable automatic model caching for a specific inference service, add the `serving.kserve.io/disable-localmodel` annotation:

[source,yaml]
----
apiVersion: serving.kserve.io/v1beta1
kind: InferenceService
metadata:
  name: llama-3-8b-no-cache
  annotations:
    serving.kserve.io/disable-localmodel: "true"
spec:
  predictor:
    model:
      modelFormat:
        name: vllm
      runtime: vllm-runtime
      storageUri: "hf://meta-llama/Meta-Llama-3-8B-Instruct"
----

[discrete]
=== Specify a target node group

To direct an inference service to a specific node group, add the `serving.kserve.io/nodegroup` annotation:

[source,yaml]
----
apiVersion: serving.kserve.io/v1beta1
kind: InferenceService
metadata:
  name: llama-3-8b
  annotations:
    serving.kserve.io/nodegroup: "gpu-group-1"
spec:
  predictor:
    model:
      modelFormat:
        name: vllm
      runtime: vllm-runtime
      storageUri: "hf://meta-llama/Meta-Llama-3-8B-Instruct"
----

[discrete]
=== Deploy an LLMInferenceService with a cached model

The model caching feature also integrates with `LLMInferenceService` resources.
The same URI matching and automatic label and annotation injection applies.

[source,yaml]
----
apiVersion: serving.kserve.io/v1alpha2
kind: LLMInferenceService
metadata:
  name: llama-3-8b-llm
spec:
  modelSpec:
    uri: "hf://meta-llama/Meta-Llama-3-8B-Instruct"
----

The `LLMInferenceService` integration is conditional on the `LLMInferenceService` CRD being installed in the cluster.
If the CRD is not installed, the controller skips `LLMInferenceService` watches.

[discrete]
=== Use namespace-scoped caches with inference services

When using a `LocalModelNamespaceCache`, the inference service must be in the same namespace as the cache resource.
The mutating webhook labels the inference service with `internal.serving.kserve.io/localmodel-namespace` instead of `internal.serving.kserve.io/localmodel`.

.Verification

* Check that the inference service pod is running and serving requests without a prolonged download phase:
+
[source,terminal]
----
$ oc get inferenceservice llama-3-8b
----
+
The `READY` status should transition to `True` within approximately 1 minute on a node with a cached model.
