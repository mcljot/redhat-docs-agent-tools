= Configure Llama Stack API providers for your deployment

[role="_abstract"]
You can select and configure the API providers that power inference, embeddings, and vector storage in your Llama Stack server.
Starting with {product-name} {product-version}, the default runtime configuration is optimized for production use with remote providers.
Inline providers for embeddings and vector storage are available as dependency-only providers that you can re-enable using a custom `config.yaml` file.

Match your provider configuration to your deployment requirements, whether you need remote providers for production workloads or dependency-only inline providers for development and testing.

.Prerequisites

* A Llama Stack distribution image based on {product-name} {product-version} or later is deployed.
* You have access to the {product-name} cluster with the Llama Stack operator installed, or you are running a standalone Llama Stack container.
* You are familiar with the Llama Stack deployment procedures from the earlier release.
* You know which API providers your current deployment uses.
