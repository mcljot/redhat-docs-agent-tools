= Track experiments with MLflow in workbenches

:context: mlflow

[role="_abstract"]
You can track machine learning experiments in workbench notebooks with the MLflow SDK.
{productname-short} provides automatic MLflow SDK configuration for workbenches, which removes the need to manually set tracking URIs, configure authentication, or manage RBAC permissions.

To use MLflow experiment tracking, a cluster administrator must first enable the MLflow Operator component, and then a data scientist can enable and use the integration in individual workbenches.
