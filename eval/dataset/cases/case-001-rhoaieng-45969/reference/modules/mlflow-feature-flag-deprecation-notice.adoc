= MLflow dashboard feature flag deprecation

[role="_abstract"]
Starting with {productname-long} 3.4, the `mlflow` field in the `OdhDashboardConfig` custom resource (CR) is deprecated.
MLflow availability in the dashboard is now determined by the `mlflowoperator` component state in the `DataScienceCluster` object, and the dashboard feature flag is no longer required.

[#mlflow-deprecated-field_{context}]
== Deprecated field

The `mlflow` field in `spec.dashboardConfig` of the `OdhDashboardConfig` CR is deprecated and no longer controls MLflow visibility in the dashboard.
You do not need to set this field to enable MLflow.
The field has no effect on MLflow functionality.

[#mlflow-current-behavior_{context}]
== Current behavior

MLflow features in the {productname-short} dashboard are automatically available when the `mlflowoperator` component is set to `Managed` in the `DataScienceCluster` object.
No additional dashboard configuration is required.

[#mlflow-pipelines-field_{context}]
== `mlflowPipelines` field

The `mlflowPipelines` field in the `OdhDashboardConfig` CR is **not** deprecated and remains active.
This field controls whether pipeline run tables display the MLflow experiment column.
Do not confuse the deprecated `mlflow` field with the active `mlflowPipelines` field.
