= Kubernetes artifacts for LangGraph agent deployment

[role="_abstract"]
When you deploy a LangGraph agent by using `make deploy`, the shared Helm chart creates several Kubernetes resources on your cluster.
You can use this reference to verify the deployment matches your cluster policies and to troubleshoot resource configuration issues.

[NOTE]
====
This reference covers only the agent-side Kubernetes artifacts created by the shared Helm chart.
Platform-side resources such as `InferenceService` and `LlamaStackDistribution` custom resources are not created by the agent Helm chart.
For platform-side resource documentation, see the link:https://docs.redhat.com/en/documentation/red_hat_openshift_ai_self-managed/3.4/html/working_with_llama_stack/deploying-llama-stack-server_rag[{product-name} Llama Stack deployment guide].
====

[discrete]
== Deployment

.Deployment resource details
[cols="2,3", options="header"]
|===
|Field
|Details

|API version
|`apps/v1`

|Purpose
|Runs the agent container with configured environment variables, resource limits, and health check probes.

|Container security context
|`runAsNonRoot: true`, `allowPrivilegeEscalation: false`, all Linux capabilities dropped. The container image defaults to UID 1001, but OpenShift can assign a different UID based on namespace security context constraints.

|Container port
|`8080` (configurable via `service.port` in the Helm values).

|Environment variables
|Core variables (`PORT`, `MODEL_ID`, `BASE_URL`) set directly. Sensitive variables (`API_KEY`, `POSTGRES_PASSWORD`, `MLFLOW_TRACKING_TOKEN`) injected from the Secret via `secretKeyRef`.

|Health checks
|Liveness probe at `/health` with 10-second initial delay and 120-second period. Readiness probe at `/health` with 5-second initial delay and 30-second period. Both configurable via `healthCheck.*` Helm values.

|Volumes
|Optional. Configured via `volumes` and `volumeMounts` in the Helm values. The Agentic RAG agent uses this to mount a PersistentVolumeClaim for the vector store.
|===

[discrete]
== Service

.Service resource details
[cols="2,3", options="header"]
|===
|Field
|Details

|API version
|`v1`

|Purpose
|Exposes the agent container within the cluster on the configured port.

|Type
|`ClusterIP` (default). Configurable via `service.type`.

|Port
|`8080` (default). Maps to the container port. Named `http`.
|===

[discrete]
== Route

.Route resource details
[cols="2,3", options="header"]
|===
|Field
|Details

|API version
|`route.openshift.io/v1`

|Purpose
|Exposes the agent externally with HTTPS access.

|TLS termination
|Edge (default). Configurable via `openshift.route.tls.termination`.

|Insecure edge policy
|`Redirect` (default). HTTP requests are redirected to HTTPS.

|Condition
|Only created when `openshift.route.enabled` is `true` (default). Set to `false` to use a Kubernetes Ingress instead.
|===

[discrete]
== Secret

.Secret resource details
[cols="2,3", options="header"]
|===
|Field
|Details

|API version
|`v1`

|Purpose
|Stores sensitive environment variable values as base64-encoded data.

|Keys
|`api-key` (from `secrets.apiKey`), `postgres-password` (from `secrets.postgresPassword`), `mlflow-tracking-token` (from `secrets.mlflowTrackingToken`). Additional keys from `extraSecrets`.

|Condition
|Only created when at least one secret value is set. If no secrets are configured, this resource is not created.
|===
