= MLflow tracing environment variables

[role="_abstract"]
You configure MLflow tracing for LangGraph agents by setting environment variables in the `.env` file.
The following table lists all available MLflow tracing variables, their scopes, and default values.

[NOTE]
====
MLflow tracing integration for LangGraph agents is planned for a future release of {product-name}.
Verify the target release version with your release team before including these modules in production documentation.
====

.MLflow tracing environment variables
[cols="2,1,1,1,3", options="header"]
|===
|Variable
|Required
|Scope
|Default
|Description

|`MLFLOW_TRACKING_URI`
|No
|Local and OpenShift
|None
|URL of the MLflow tracking server. Setting this variable is the single switch that enables tracing. If not set, no MLflow packages are imported and the agent runs without tracing.

|`MLFLOW_EXPERIMENT_NAME`
|No
|Local and OpenShift
|`default-agent-experiment`
|Name of the MLflow experiment for organizing traces. Each agent can use a different experiment name to separate traces.

|`MLFLOW_HEALTH_CHECK_TIMEOUT`
|No
|Local and OpenShift
|`5`
|Number of seconds the agent waits for the MLflow server to respond during startup health check. If the server is unreachable after this timeout, the agent continues without tracing.

|`MLFLOW_HTTP_REQUEST_TIMEOUT`
|No
|Local and OpenShift
|`2`
|Timeout in seconds for individual MLflow HTTP requests during normal operation. The agent templates default to `2` seconds for local development. The MLflow library default is `120` seconds.

|`MLFLOW_HTTP_REQUEST_MAX_RETRIES`
|No
|Local and OpenShift
|MLflow default
|Maximum number of retries for failed MLflow HTTP requests during normal operation.

|`MLFLOW_TRACKING_TOKEN`
|No
|OpenShift only
|None
|Authentication token for the MLflow instance on OpenShift. Obtain this from the OpenShift console. Stored as a Kubernetes Secret when deployed.

|`MLFLOW_TRACKING_INSECURE_TLS`
|No
|OpenShift only
|None
|Set to `true` if the OpenShift cluster uses self-signed TLS certificates.

|`MLFLOW_WORKSPACE`
|No
|OpenShift only
|None
|Project or workspace name for the MLflow instance on OpenShift.

|`MLFLOW_TRACKING_AUTH`
|No
|OpenShift only
|None
|Use Kubernetes service account authentication when running inside the cluster, instead of a token.
|===
