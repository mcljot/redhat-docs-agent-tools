= Enable MLflow tracing for agents deployed on OpenShift

[role="_abstract"]
You can enable MLflow tracing for agents deployed on {product-name} to monitor production agent performance and debug execution issues.
Traces are sent to the OpenShift-hosted MLflow instance and are viewable in the MLflow UI.

[NOTE]
====
MLflow tracing integration for LangGraph agents is planned for a future release of {product-name}.
Verify the target release version with your release team before including these modules in production documentation.
====

.Prerequisites

* A LangGraph agent is deployed on OpenShift. See xref:deploying-a-langgraph-agent-to-openshift_{context}[Deploy a LangGraph agent to Red Hat OpenShift AI].
* An MLflow instance is available on your OpenShift cluster.

.Procedure

. Configure the MLflow tracing environment variables in the agent's `.env` file before deploying.
+
In the following example, replace the placeholder values with your OpenShift cluster details:
+
[source,ini]
----
MLFLOW_TRACKING_URI=https://<openshift-dashboard-url>/mlflow
MLFLOW_TRACKING_TOKEN=<your-openshift-token>
MLFLOW_EXPERIMENT_NAME=<your-experiment-name>
MLFLOW_TRACKING_INSECURE_TLS=true
MLFLOW_WORKSPACE=default
----
+
--
Where:

`MLFLOW_TRACKING_URI`:: The URL of the MLflow server on your OpenShift cluster.
`MLFLOW_TRACKING_TOKEN`:: Your OpenShift authentication token, obtained from the OpenShift console.
`MLFLOW_TRACKING_INSECURE_TLS`:: Set to `true` if your cluster uses self-signed TLS certificates.
`MLFLOW_WORKSPACE`:: The project or workspace name for the MLflow instance.
--

. Deploy or redeploy the agent:
+
[source,terminal]
----
$ make deploy
----
+
The `MLFLOW_TRACKING_TOKEN` value is passed to the cluster as a Kubernetes Secret and injected as an environment variable.

.Verification

. Send a request to the deployed agent to generate a trace:
+
In the following command, replace `<route-url>` with the agent's OpenShift Route URL:
+
[source,terminal]
----
$ curl -X POST https://<route-url>/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"messages": [{"role": "user", "content": "Hello!"}], "stream": false}'
----

. Open the MLflow UI on your OpenShift cluster and navigate to the experiment specified in `MLFLOW_EXPERIMENT_NAME`.

. Verify that a trace is displayed for the request, with spans for agent orchestration, LLM calls, and tool executions.
