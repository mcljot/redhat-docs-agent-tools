= Enable MLflow tracing for local agent development

[role="_abstract"]
You can enable MLflow tracing to inspect your agent's LLM calls, tool executions, and orchestration spans during local development.
Traces appear in the MLflow UI, where you can examine the execution hierarchy for each request.

[NOTE]
====
MLflow tracing integration for LangGraph agents is planned for a future release of {product-name}.
Verify the target release version with your release team before including these modules in production documentation.
====

.Prerequisites

* A LangGraph agent is running locally. See xref:running-a-langgraph-agent-locally_{context}[Run a LangGraph agent locally].

.Procedure

. Add the MLflow tracing environment variables to the agent's `.env` file:
+
[source,ini]
----
MLFLOW_TRACKING_URI=http://localhost:5000
MLFLOW_EXPERIMENT_NAME=my-agent-experiment
MLFLOW_HEALTH_CHECK_TIMEOUT=5
MLFLOW_HTTP_REQUEST_TIMEOUT=2
MLFLOW_HTTP_REQUEST_MAX_RETRIES=0
----

. Start the local MLflow server in a separate terminal:
+
[source,terminal]
----
$ uv run --extra tracing mlflow server --port 5000
----

. Start the agent:
+
[source,terminal]
----
$ make run-app
----
+
When `MLFLOW_TRACKING_URI` is set, `make run-app` automatically installs the MLflow tracing dependencies by using the `[tracing]` extra.

. Send a request to the agent to generate a trace:
+
[source,terminal]
----
$ curl -X POST http://localhost:8000/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"messages": [{"role": "user", "content": "Hello!"}], "stream": false}'
----

.Verification

. Open the MLflow UI at `http://localhost:5000` in a browser.

. Navigate to the experiment specified in `MLFLOW_EXPERIMENT_NAME`.

. Verify that a trace is displayed for the request you sent. The trace contains spans for:
+
* Agent orchestration (LangGraph chain)
* LLM calls (ChatOpenAI)
* Tool executions (if the agent called any tools)

.Troubleshooting

* If no traces appear, check the agent startup logs for tracing-related messages. A message such as `[Tracing] MLFLOW_TRACKING_URI not set. Tracing is disabled.` indicates the environment variable is not set or not loaded.
* If the agent logs `[Tracing] MLflow server is unreachable`, verify the MLflow server is running on the expected port.
