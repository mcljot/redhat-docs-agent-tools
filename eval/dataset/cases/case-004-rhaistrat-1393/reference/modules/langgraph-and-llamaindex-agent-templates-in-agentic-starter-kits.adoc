= LangGraph and LlamaIndex agent templates in agentic starter kits

[role="_abstract"]
{product-name} {product-version} introduces LangGraph and LlamaIndex agent templates in the agentic starter kits.
You can use these templates to build AI agents locally and deploy them to {product-name} production by changing only environment configuration.

The LangGraph templates include the following agents:

* **ReAct agent** -- general-purpose agent that reasons and calls tools step by step.
* **Agentic RAG** -- retrieval-augmented generation agent that indexes documents in Milvus and retrieves relevant chunks to augment answers.
* **Human-in-the-Loop** -- agent with approval workflows that pauses for human review before executing sensitive tools.
* **Database Memory** -- ReAct agent with PostgreSQL-backed conversation memory for persistent, thread-based chat history.

The LlamaIndex templates include a web search agent.

All templates use the OpenAI-compatible chat completions API (`ChatOpenAI` from LangChain) to connect to model endpoints.
You can serve models locally with Ollama or Llama Stack, and in production with vLLM or llm-d on {product-name}.
You deploy agents by updating environment variables to point to production model serving endpoints.
No application code changes are required.

For more information, see the link:https://github.com/red-hat-data-services/agentic-starter-kits/tree/main/agents[agentic starter kits agent catalog].
