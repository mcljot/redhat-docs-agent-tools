= Build and deploy LangGraph agents

[role="_abstract"]
As a developer, you can build AI agents from LangGraph starter kit templates, run them locally for testing, and deploy them to {product-name} by changing only environment configuration.
The agentic starter kits provide four ready-to-use agent templates with a standardized Makefile interface and Helm-based deployment workflow.

.Prerequisites

* `uv` is installed for Python dependency management.
* Ollama or access to an OpenAI-compatible model serving endpoint is available for local development.
* `oc` CLI, Helm 3, and GNU Make are installed for OpenShift deployment.
