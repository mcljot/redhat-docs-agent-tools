= Manage deployed agents with Kagenti

[role="_abstract"]
As a system administrator, you can register deployed agents with Kagenti for centralized discovery and lifecycle management.
Kagenti is a Kubernetes operator that provides a UI for monitoring and managing AI agents on your OpenShift cluster.

[IMPORTANT]
====
Kagenti uses API version `agent.kagenti.dev/v1alpha1`.
The `v1alpha1` designation indicates the API can change before reaching general availability.
A preview of Kagenti on {product-name} is planned for the second half of 2026.
====
